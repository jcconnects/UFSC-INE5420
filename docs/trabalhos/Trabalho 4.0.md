# Trabalho 4.0 - Modelos Hierárquicos com OpenGL ou Game Engine (atualizado)

Vencimento: domingo, 20 dez. 2026, 09:41

---

O último trabalho da disciplina consiste em implementar um modelo hierárquico para simular a movimentação de alguma forma animal (um robô, algum bicho, uma pessoa, etc). Esta simulação deve conter dois tipos de movimentação, como andar e correr. Não basta um tipo apenas! Na [página](http://www.inf.ufsc.br/~grafica/modelosHierarquicos/caminhar/index.html) do professor encontra-se um material sobre modelos hierárquicos para auxiliar no trabalho. No site também estão à disposição alguns trabalhos de semestres anteriores que podem nortear algum grupo com dúvida.

## Plataforma/Ambiente

O trabalho pode ser realizado tanto em:

- Um Game Engine (UE4 ou Unity3D), nesse caso utilizando-se um modelador 3D (Atualmente: Blender) para a criação da forma do personagem. Nesse caso deve-se utilizar o modelo de movimentação de esqueleto do Game Engine escolhido
- OpenGL/GLUT. A maioria dos trabalhos de semestres anteriores utilizou OpenGL em C ou C++, mas o grupo pode utilizar sua linguagem de programação de preferência (a grande maioria das linguagens possui bindings pra OpenGL).
